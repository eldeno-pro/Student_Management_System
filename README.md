## Group Project & Branch Strategy

This repository adheres to the Git collaboration guidelines:
* `main`: Production-ready, stable codebase.
* `develop`: Active integration branch for all merged pull requests.
* **Feature Branches**:
  * `feature/database-relationships`: Migrations, models, and Eloquent relationships (Question 1)
  * `feature/seeders-and-sample-data`: Seeders for students, courses, user accounts, and registrations (Question 2)
  * `feature/auth-and-roles`: Authentication, Spatie role-and-permission access control, and route middleware (Question 3)
  * `feature/student-management`: Student CRUD operations and role-based policies (Question 4)
  * `feature/course-and-registration`: Course CRUD and course registration with duplicate prevention (Question 4)
  * `feature/blade-layouts-and-views`: Blade layout, navigation permissions, and form validation (Question 5)
  * `feature/documentation`: Installation instructions, sample credentials, and application report (Question 6)
